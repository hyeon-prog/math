# MathInk (매스잉크)

노트북 정밀 터치패드(Windows Precision Touchpad)에 손가락으로 수학 기호·화학식을
그리면 화면 오버레이에 실시간 표시되고, 학습된 필체와 비교해 텍스트로 변환해주는
프로그램. 외부 패키지 불필요 (표준 라이브러리만, Windows 전용).

## 실행

가장 간단한 방법은 **바탕화면의 "매스잉크" 바로가기 더블클릭** (터미널 불필요).

터미널에서 실행할 때는 **먼저 프로그램 폴더로 이동**해야 한다
(다른 폴더에서 `python mathink.py`를 치면 파일을 찾지 못해 실행되지 않음):

```
cd C:\claude\mathink                  ← 프로그램 폴더로 이동 (필수)

python mathink.py                     ← 일반 실행
python mathink.py --train "0 1 + ="   ← 나열한 기호를 3번씩 그려 일괄 학습
python mathink.py --probe             ← 터치패드 감지 확인
python mathink.py --dump              ← 터치 이벤트를 콘솔에 출력 (디버깅)
```

폴더 이동 없이 실행하려면 전체 경로 사용: `python C:\claude\mathink\mathink.py`

## 입력 흐름

1. `F8` → 드로잉 모드 (커서 고정·클릭 차단, 키보드는 동작)
2. 기호를 그리고 **잠시(0.6초) 멈추면** 인식 — 잉크가 회색으로 남고 위에 라벨 표시
3. 기호를 이어 그려 식을 완성 → **`Enter`를 누르면** 텍스트로 확정
   (자동 확정 없음 — 천천히 써도 중간에 확정되지 않음)
4. 확정된 텍스트는 **원래 쓰던 앱의 커서 위치에 바로 타이핑**된다
   (오버레이가 포커스를 뺏지 않으므로 메모장·한글 등에 이어서 입력됨.
   `A`키로 끄면 타이핑하지 않고, Esc로 나갈 때 클립보드로만 전달)
5. `Esc` → 종료, 전체 결과가 **클립보드로도 복사**됨 (안전망)

### 기호 자동 분리 (멈추지 않아도 되는 경우)

- **옆으로 이어 쓴 글자**: 새 획이 기존 획들과 가로로 겹치지 않으면 즉시 분리.
  획이 겹치는 다획 기호(`+`, `=`, `x`, `t` 등)는 분리되지 않음
- **분수**: 막대를 분자보다 1.3배 이상 넓게 그리면 분자가 즉시 확정되고,
  막대 위에 분자가 있으면 아래에 분모를 바로 이어 쓸 수 있음

## 단축키 (드로잉 모드 중, 하단 패널에 항상 표시)

| 키 | 동작 |
|---|---|
| `Enter` | 화면의 기호들을 즉시 텍스트로 확정 |
| `← →` | 기호 선택 (주황색 강조, 인식 후보 표시, 선택 중 자동 확정 정지) |
| `1·2·3` | 선택한 기호를 인식 후보 1~3번으로 교체 (그 필체가 자동 학습됨) |
| `U` | 선택한(없으면 마지막) 글자의 대/소문자 전환 — 전환한 글자는 이후 판정 기준 |
| `T` | 선택한(없으면 마지막) 기호를 직접 입력으로 교정·학습 |
| `Ctrl+Z` | 마지막 학습 취소 (잘못 학습시킨 샘플 삭제, 연속 사용 가능) |
| `Backspace` | 선택 기호 삭제 → 그리던 획 취소 → 마지막 기호 취소 → 결과 글자 삭제 |
| `Space` | 결과에 공백 추가 |
| `C` | 화면 전체 취소 |
| `S` | 획 데이터 JSON 저장 (디버깅용) |
| `Esc` / `F8` | 드로잉 모드 끄기 (결과를 클립보드로 복사) |
| `Ctrl+F8` | 프로그램 완전 종료 |

## 배치 해석 규칙 (확정 시점에 적용)

### 분수
분자·가로 막대·분모를 위-가운데-아래로 그리면 `(분자)/(분모)`.
`-`로 인식된 기호의 가로 범위 안에 위/아래 기호가 모두 있으면 분수 막대로 판정.
중첩 분수 가능 (바깥 막대를 더 넓게). 막대 좌우 옆의 기호는 일반 기호 (`3-4`는 뺄셈).

### 윗첨자/아래첨자
기준 기호 중심에서 세로로 벗어나게 그리면 첨자로 인식된다 (글자 뒤 숫자는
민감하게 판정). 출력은 유니코드 첨자: `x²`, `H₂O`, `SO₄²⁻`, `C₆H₁₂O₆`.
유니코드에 없는 문자가 섞이면 `x^(1/2)`처럼 ^( )/_( ) 표기로 폴백하고,
여러 글자 밑은 괄호로 감싼다(`(1/2)³`).
**알파벳끼리는 첨자로 판정하지 않음** (`Na`가 `N_a`가 되지 않음 — 첨자는 숫자·기호만).
꼬리 글자(g,j,p,q,y)는 중심이 낮아지는 것을 보정.

### 대소문자 (화학식용)
모양이 같은 쌍(c,j,o,p,s,u,v,w,x,y,z)은 **상대 크기**로 판정. 셋 중 하나면 대문자:
1. 패드 세로의 60% 이상 (절대)
2. 같은 식의 확실한 대문자(H, N 등 모양이 다른 것, U키로 지정한 것)의 80% 이상
3. 식에서 가장 작은 글자의 1.5배 이상 (그리고 30% 이상)

애매하면 `U`키로 전환 — 전환된 글자가 기준점이 되어 나머지도 따라감 (CO₂에서
C만 U로 바꾸면 O도 자동 대문자). 모양이 다른 쌍(A/a, B/b 등)은 모양으로 구분.

### 점(.)
크기 정보가 정규화로 사라지므로, 아주 작게 그린 입력(패드 세로의 6% 미만)은 점.

## 인식 방식

1. Raw Input API로 터치패드 HID 디지타이저(Usage 0x0D/0x05)의 좌표를 직접 수신
2. **CNN 분류기**: CROHME 8.5만 샘플로 학습한 작은 합성곱 신경망(89종).
   획을 28x28 이미지로 렌더링해 분류하며, 추론은 numpy만으로 수 ms에 동작
   (`nn_model.npz`가 없으면 자동으로 $P 단독 모드)
3. **$P 포인트 클라우드**: 획을 32개 점으로 정규화해 템플릿과 탐욕 매칭.
   사용자가 T키로 즉시 학습시키는 개인 필체와 CNN이 모르는 기호 담당
4. 두 점수를 융합해 최종 후보 결정 — held-out 기준 $P 단독 62% → 융합 90%
   (89종). 교정(1~3/T)할 때마다 본인 필체가 학습되어 계속 좋아짐
5. 재학습: `pip install torch` 후 `python train_nn.py --zip CROHME_full_v2.zip`
   (약 8분, 앱 실행에는 torch 불필요)

## 학습 데이터 관리 (잘못 학습한 것 지우기)

개인 필체는 `templates.json`에 저장된다. 상황별 지우는 방법:

**① 방금 실수했을 때** — 터미널 필요 없음. 드로잉 모드에서 그대로 `Ctrl+Z`
(마지막 학습부터 차례로 취소).

**② 시간이 지난 뒤 발견했을 때** — 터미널에서 관리 도구 사용:

1. **매스잉크를 먼저 종료** (`Ctrl+F8`) — 켜둔 채 지우면 앱이 메모리에 있는
   데이터를 다시 저장해서 지운 것이 되살아난다
2. 터미널 열기 (VS Code에서 `` Ctrl+` `` 또는 시작 메뉴 → "명령 프롬프트")
3. 프로그램 폴더로 이동 후 명령 실행:

```
cd C:\claude\mathink

python manage_templates.py list          ← 어떤 라벨이 몇 개씩 있는지 목록
python manage_templates.py show t        ← 't'의 샘플들을 그림으로 확인 (번호 표시)
python manage_templates.py remove t 9    ← 그중 9번 샘플만 삭제
python manage_templates.py remove-last t 2   ← 't'의 최근 샘플 2개 삭제
python manage_templates.py delete t      ← 't' 라벨 통째로 삭제
```

4. 바탕화면 바로가기로 매스잉크 다시 실행

- 모든 수정 전에 `templates.json.bak` 백업이 자동 생성된다 (실수하면 이 파일을
  `templates.json`으로 복사해 복원)
- **잘못 학습됐다는 신호**: 특정 기호가 갑자기 엉뚱한 것으로 인식되기 시작하면
  그 엉뚱한 라벨을 `show`로 열어 이상한 모양의 샘플을 찾아 지운다.
  `list`에서 의도하지 않은 여러 글자짜리 라벨(예: `Na`)이 보여도 오학습이다

**③ 외부 데이터 추가**: `python import_crohme.py CROHME_full_v2.zip [--list | --only "..."]`
(zip 출처: [ThomasLech/CROHME_extractor](https://github.com/ThomasLech/CROHME_extractor)의 `data/`)

## 알려진 한계

- `l`(엘)은 `1`과 모양이 같아 기본 세트에서 제외 — 필요하면 고리 있는 필기체 ℓ를
  T키로 학습 권장. `o`/`O`/`0`도 모양이 같아 후보 교체로 잡아야 함
- 알파벳 밑 문자 첨자(`a_n`)는 비활성화됨 (화학식 오인 방지와 트레이드오프)
- 분자와 막대의 너비가 비슷한 분수는 부품 사이 0.6초 멈춤 필요 (`=`와 구분 불가)
