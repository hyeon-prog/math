# touchpad-draw

노트북 정밀 터치패드(Windows Precision Touchpad)에 손가락으로 수학 기호를 그리면
화면 위 투명 오버레이에 실시간으로 궤적이 표시되고, 학습된 필체와 비교해
텍스트로 변환해주는 프로그램.

## 실행

```
python touchpad_draw.py                     # 일반 실행
python touchpad_draw.py --train "0 1 + ="   # 나열한 기호를 3번씩 그려 일괄 학습
```

외부 패키지 불필요 (표준 라이브러리만 사용, Windows 전용).

## 사용법

1. `F8`을 눌러 드로잉 모드를 켠다 (점선 사각형 = 터치패드 매핑 영역)
2. 터치패드에 한 손가락으로 기호를 그린다 (여러 획 가능, 예: `=`, `+`)
3. **잠시(1초) 멈추면** 기호 하나가 인식됨 — 잉크가 회색으로 남고 위에 라벨 표시
4. 기호를 계속 이어 그린 뒤 **Enter(또는 2.5초 대기)**로 텍스트 확정
5. `Esc`로 나가면 결과 텍스트가 **클립보드에 복사**되어 아무 데나 붙여넣기 가능

### 분수 쓰기

분자를 위에, 가로 막대를 가운데에(분자보다 넓게), 분모를 아래에 그린 뒤
확정하면 `(분자)/(분모)` 형태로 변환된다. 예: `1` `─` `2` → `1/2`,
`x+1` `─` `2y` → `(x+1)/(2y)`. 중첩 분수도 가능하다 (바깥 막대를 더 넓게).
막대 좌우 바깥에 그린 기호는 분수와 무관한 일반 기호로 처리된다 (`3-4`는 그냥 뺄셈).

| 키 (드로잉 모드 중) | 동작 |
|---|---|
| `F8` / `Esc` | 드로잉 모드 끄기 (결과를 클립보드로 복사) |
| `Enter` | 화면의 기호들을 즉시 텍스트로 확정 |
| `T` | 마지막 기호 학습 — 오인식 교정에도 사용 (확정 전) |
| `Backspace` | 그리던 획 취소 → 마지막 기호 취소 → 결과 글자 삭제 순 |
| `Space` | 결과에 공백 추가 |
| `C` | 화면 전체 취소 |
| `S` | 획 데이터 JSON 저장 (디버깅용) |
| `Ctrl+F8` | 프로그램 완전 종료 |

드로잉 모드 중에는 마우스 커서 이동/클릭이 차단된다 (키보드는 정상 동작).

## 외부 데이터셋 가져오기

CROHME(온라인 손글씨 수식 인식 대회) 데이터셋에서 다른 사람들의 필체를
기호 템플릿으로 가져올 수 있다. 숫자·연산자·괄호·그리스 문자 등 44종이
기본 세트로 이미 가져와져 있다 (기호당 12개 필체, `templates.json`).

```
python import_crohme.py CROHME_full_v2.zip           # 기본 세트 가져오기
python import_crohme.py CROHME_full_v2.zip --list    # 사용 가능한 라벨 확인
python import_crohme.py CROHME_full_v2.zip --only "\sin \cos \log"
```

zip은 [ThomasLech/CROHME_extractor](https://github.com/ThomasLech/CROHME_extractor)
저장소의 `data/CROHME_full_v2.zip` (CROHME 2013, 연구/교육 목적).
남의 필체 기준 held-out 정확도는 44종에서 약 80%이며, 자기 필체를
T키로 몇 번 교정하면 개인 정확도는 그보다 훨씬 높아진다.

점(`.`)은 크기 정보가 정규화로 사라져 템플릿 매칭이 불가능하므로,
"터치패드 세로의 6% 미만으로 아주 작게 그린 입력은 점"이라는 규칙으로 처리한다.

## 학습 (자신의 필체 등록)

두 가지 방법:

- **일괄 학습**: `python touchpad_draw.py --train "0 1 2 3 + - ="` 처럼 실행하고
  F8을 누르면 안내에 따라 각 기호를 3번씩 그리게 된다.
  라벨은 공백으로 구분하며 여러 글자짜리(`\pi`, `sin` 등)도 가능하다.
- **즉석 학습/교정**: 일반 모드에서 기호를 그린 뒤 `T`를 누르고 라벨을 입력.
  오인식됐을 때 누르면 방금 붙은 글자를 올바른 라벨로 교체하면서 학습까지 된다.
  **쓰다 보면 자주 틀리는 기호에 샘플이 쌓여 점점 정확해진다.**

학습 데이터는 `templates.json`에 저장된다 (삭제하면 초기화).

## 진단

```
python touchpad_draw.py --probe   # 정밀 터치패드 감지 여부 확인
python touchpad_draw.py --dump    # GUI 없이 터치 이벤트를 콘솔에 출력
```

## 동작 원리

1. Raw Input API로 터치패드의 HID 디지타이저 컬렉션(Usage Page 0x0D, Usage 0x05)을 구독
2. `HidP_*` 함수로 각 접점의 X/Y 좌표와 tip switch(접촉 여부)를 파싱
3. tkinter 투명 전체화면 오버레이(`-transparentcolor`)에 궤적을 폴리라인으로 렌더링
4. 드로잉 모드 중에는 저수준 마우스 훅(`WH_MOUSE_LL`)으로 커서 입력을 차단
5. 1초 멈춤으로 구분된 획 묶음을 $P 포인트 클라우드 인식기([recognizer.py](recognizer.py))로
   학습된 템플릿과 비교해 가장 가까운 기호를 선택
6. 확정 시점에 기호들의 위치 관계를 해석: `-`로 인식된 기호의 가로 범위 안에
   위·아래 기호가 모두 있으면 분수 막대로 보고 재귀적으로 `(분자)/(분모)` 변환
